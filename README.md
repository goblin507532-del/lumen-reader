# Lumen Reader

Десктопная читалка и «второй мозг» для Windows. Книги, рецепты, гайды и заметки
в одном окне: обложки, цветные выделения, теги, поиск по всему, бесплатные онлайн-каталоги.

## Что внутри

**Библиотека**
- Форматы: FB2, FB2.ZIP, EPUB, TXT, Markdown, HTML, RTF, DOCX, PDF (PDF открывается во встроенном просмотрщике).
- Обложка, автор, серия, аннотация и язык подхватываются из файла; обложку можно заменить своей.
- Кодировка windows-1251 в FB2 определяется автоматически.
- Полка «Продолжить чтение», коллекции, теги, избранное, фильтры (читаю / новые / прочитано), сетка или список.
- Перетаскивание файлов и папок прямо в окно.

**Читалка**
- Постраничный режим (одна или две страницы разворотом) либо обычная прокрутка.
- Темы: Ночь, Чернила, Сепия, Бумага; акцентный цвет; кегль, интерлиньяж, ширина полосы, выключка.
- Содержание, закладки, поиск по книге, сноски FB2 по клику.
- Выделение текста пятью цветами, заметка к цитате, копирование, отправка цитаты во «Второй мозг».
- Позиция чтения и процент сохраняются автоматически.

**Второй мозг**
- Типы записей: рецепт, гайд, заметка, идея — у каждого свои поля (время, порции, сложность, уровень, источник).
- Markdown-редактор с живым предпросмотром: заголовки, списки, чек-листы, таблицы, цитаты, код, `==выделение==`, картинки, ссылки `[[вики-ссылки]]` на другие записи и книги.
- Шаблоны рецепта и гайда в один клик, обложка записи, теги, закрепление, вставка картинки из буфера обмена.
- Импорт `.md`, экспорт одной записи или всей базы.

**Выделения**
- Все цитаты из всех книг на одном экране, фильтр по цвету и поиску, переход к месту в книге, экспорт в `.md`,
  сборка всех цитат книги в отдельную запись «Второго мозга».

**Перевод**
- Панель перевода прямо в читалке: язык, движок, манера, словарь имён и терминов.
- Режимы: параллельно (оригинал приглушён, перевод под ним) или только перевод.
- Движки без ключа: быстрый машинный, LibreTranslate (можно свой сервер), MyMemory — переключаются
  автоматически, если один не ответил.
- Литературный режим через LLM (Claude или любой OpenAI-совместимый API): переводит абзацами целиком,
  видит предыдущий кусок перевода и словарь, поэтому имена и интонация не скачут.
- Кнопка «Перевести всю книгу» прогоняет все главы подряд с прогрессом и остановкой; готовые главы
  берутся из кэша и открываются сразу. «Авто» переводит следующую главу заранее.
- Перевод кэшируется по книге, главе и языку и переживает перезапуск.
- Записи «Второго мозга» переводятся кнопкой: заменить, дописать ниже или создать отдельную запись.

**Рецепт со страницы**
- Кнопка «Вставить рецепт со страницы»: ссылка или вставка скопированной страницы (Ctrl+V сохраняет вёрстку).
- Разбирает `schema.org/Recipe` (JSON-LD и микроразметку), а без разметки — по заголовкам, спискам
  и таблицам шагов «номер + фото + текст».
- На выходе Markdown: ингредиенты чек-листом, пронумерованные шаги с фото, заметки, ссылка на источник.
- Картинки скачиваются в локальное хранилище, первая становится обложкой записи; время, порции и кухня
  попадают в поля рецепта. Можно сразу перевести на нужный язык.

**Каталоги и поиск**
- Одно поле поиска спрашивает **все каталоги сразу**, ответы приходят потоком — как вкладки браузера,
  только внутри приложения; результаты сгруппированы по источнику.
- Источники: Internet Archive (миллионы оцифрованных книг, в том числе на русском), Open Library
  (каталог всех книг мира — что существует и где читать), Project Gutenberg (API и OPDS, включая
  русскоязычный раздел), ManyBooks, Standard Ebooks.
- Любой свой OPDS-фид добавляется в настройках: домашний Calibre-сервер, корпоративная библиотека,
  любой каталог, который поддерживает OPDS.
- Скачивание сразу кладёт книгу в библиотеку вместе с обложкой.

**Ресурсы**
- Куча памяти под большие книги: `--max-old-space-size=8192`, дисковый кэш 512 МБ, фон не тормозится.
- Разобранная книга кэшируется на диск, так что повторное открытие мгновенное.

## Установка

В папке `dist`:
- `LumenReader-portable-1.2.0.exe` — запускается без установки.
- `LumenReader-setup-1.2.0.exe` — установщик с выбором папки и ярлыком на рабочем столе.

Данные (книги, обложки, заметки, выделения) лежат в `%APPDATA%\Lumen Reader\data`.
Кнопка «Резервная копия» в настройках выгружает всю базу одним JSON-файлом.

## Горячие клавиши

| Клавиши | Действие |
|---|---|
| `Ctrl+K` | поиск по книгам, записям и цитатам |
| `Ctrl+O` | добавить книгу |
| `Ctrl+N` | новая запись |
| `Ctrl+S` | сохранить запись |
| `Ctrl+F` | поиск внутри книги |
| `←` `→` `Space` | страницы |
| `B` / `T` | закладка / содержание |
| `Esc` | назад, закрыть панель |

## Разработка

```powershell
cd C:\Mods\...\LumenReader   # папка проекта
npm start                     # запуск из исходников
node tools\make-icon.js       # перегенерировать build\icon.ico
```

Сборка exe (electron-builder на этой машине не может распаковать `winCodeSign` без прав на симлинки,
поэтому иконка проставляется вручную через `rcedit`, а правка exe самим билдером отключается):

```powershell
npx electron-builder --win portable nsis --config.win.signAndEditExecutable=false
& "$env:LOCALAPPDATA\electron-builder\Cache\winCodeSign\<id>\rcedit-x64.exe" `
    "dist\win-unpacked\Lumen Reader.exe" --set-icon build\icon.ico `
    --set-version-string FileDescription "Lumen Reader" --set-file-version 1.2.0
npx electron-builder --win portable nsis --prepackaged dist\win-unpacked --config.win.signAndEditExecutable=false
```

Смоук-тест с скриншотами (импортирует все книги из папки, прогоняет все экраны и выходит):

```powershell
$env:LUMEN_SELFTEST = "C:\путь\к\книгам"; $env:LUMEN_SHOTS = "C:\путь\для\скриншотов"
npm start
```

## Структура

```
src/main.js          процесс Electron: окно, IPC, импорт, каталоги
src/preload.js       мост в рендерер
src/lib/fb2.js       FB2 -> HTML, обложка, сноски
src/lib/epub.js      EPUB: OPF, spine, навигация, картинки в data-URI
src/lib/parse.js     диспетчер форматов (txt/md/html/rtf/docx/zip)
src/lib/markdown.js  Markdown -> HTML (общий для книг и записей)
src/lib/opds.js      Gutendex и OPDS-каталоги, скачивание
src/lib/translate.js движки перевода: машинные и литературный через LLM
src/lib/recipe.js    страница -> структурированный рецепт в Markdown
src/lib/store.js     библиотека на диске, кэш разбора, обложки
src/ipc-extra.js     IPC перевода и захвата рецептов
src/renderer/        интерфейс: library / reader / brain / catalog / перевод
```
