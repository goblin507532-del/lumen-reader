Синхронизация с телефоном

Книги, заметки, выделения и позиция чтения живут в твоём приватном GitHub-репозитории. Сервер не нужен, данные не уходят никому постороннему.

Телефон

Android-приложение собирается на GitHub Actions и выкладывается в релизы — APK скачивается прямо на телефон.

Горячие клавиши

  • Ctrl+K — поиск по всему
  • Ctrl+O — добавить книгу
  • Ctrl+N — новая запись
  • ← → / Space — страницы в читалке
  • Ctrl+F — поиск в книге
  • Esc — назад / закрыть
